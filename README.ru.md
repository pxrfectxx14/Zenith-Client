# Zenith Client

[English](README.md) | [Русский](README.ru.md)

Fabric-клиент-мод для Minecraft 1.21.6.

## ⚠ WARNING!

**Мод может быть нестабильным. Если нашли ошибки, имеете правки/идеи пишите на почту — _solareclipse12@inbox.eu_ или на мой Discord — _zenith.client_support_**.

## Возможности

- **Уведомление о входе в биом** — при смене биома, появляется короткое уведомление, каждому биому присвоен свой текст.
- **Поиск предметов в сундуках** — есть переключатель «фильтр/подсветка» в зависимости от опции, предметы либо буду прикрываться, либо подсвечиваться.
- **Реальные часы** — в левом верхнем углу находятся часы, совпадающие со временем на вашем устройстве.
- **Игровые часы** — рядом с часами реального времени, находятся часы игрового времени. Они показывают сколько времени осталось до ночи/рассвета.
- **Счетчик урона** — при нанесении урона фича будет показывать нанесенное количество сердец и какому моб/игрок был ранен.
- **Координаты** — слева внизу от инвентаря находится едва заметные координаты игрока.
- **Частицы биомов** — от каждого биома будут идти едва заметные частицы.
- **Светящийся курсор** — кастомная светящаяся стрелка вместо системного курсора ОС, со следом из мерцающих искр и мягким фоновым свечением (glow), которое плавно следует за мышью.
- **Меню мода** — открывается по настраиваемой клавише (по умолчанию `Right Shift`), позволяет включать/выключать каждую фичу мода по отдельности.
- **Встроенный ресурспак (`Zenith GUI`)** — тёмная тема интерфейса, переключается прямо из меню мода (Options → Resource Packs недоступен для управления, только через меню/файл пака).
- **Куча разных мелких фич** — смена оттенка текста, частицы от курсора и тд.

## Требования

- Minecraft 1.21.6
- Fabric Loader
- Fabric API

## Установка
Скачайте zenith-client-1.0.0-beta.1.jar во вкладке "Releases" и положите его в корневую папку игры minecraft/mods.

_Либо (для разработки):_
```bash
git clone https://github.com/pxrfectxx14/Zenith-Client
cd zenith-client-template-1.21.6
./gradlew runClient
```

## Структура проекта

```
src/main/java/dev/zenith/client/
├── feature/          # Базовые классы фич
├── menu/             # Экран меню мода, список фич, регистрация ресурспака
├── mixin/            # Mixin'ы
└── ZenithClientClient.java   # Точка входа клиента

src/main/resources/
├── assets/zenith-client/     # Текстуры, язык, спрайты курсора/искр
└── resourcepacks/zenith-gui/ # Встроенный тёмный ресурспак
```

## Управление

| Действие              | Клавиша по умолчанию |
|-----------------------|-----------------------|
| Открыть меню мода      | `Right Shift`         |

Клавишу можно переназначить в **Controls → Zenith Client**.

## Известные ограничения

- 1.21.6 использует новую двухфазную систему рендера GUI — часть внутренних API Minecraft ещё нестабильна между патч-версиями, поэтому обновление на новую версию Minecraft может потребовать правок в мод-коде рендера.
